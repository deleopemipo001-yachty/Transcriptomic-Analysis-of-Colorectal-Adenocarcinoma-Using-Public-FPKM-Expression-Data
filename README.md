# Transcriptomic Analysis of Colorectal Adenocarcinoma Using Public FPKM Expression Data
Colorectal adenocarcinoma is one of the leading causes of cancer-related mortality worldwide.  This project investigates transcriptomic alterations associated with colorectal adenocarcinoma using publicly available RNA-Seq expression data.
Processed FPKM expression data from GEO (GSE142279) was used. 
No raw FASTQ processing (QC/alignment) was performed.
Differential expression analysis was conducted using limma in R.
